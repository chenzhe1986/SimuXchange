# SimuXchange 项目简介

SimuXchange 是一款**模拟交易所交易网关（TGW）**的跨平台测试工具：假扮真实
交易所网关，接受柜台系统（OMS）的 TCP 连接与委托（上海综合网关则通过
SQL Server 接口表交换 STEP 委托/回报），按配置的策略回送确认 /
成交 / 拒单 / 撤单回报。不撮合、无真实行情，专门用于柜台系统的联调与
自动化回归测试。

## 核心特色

- **四类交易所接入**：深交所统一网关（Binary）、上交所竞价平台（Binary 0.54）、
  上交所新债券平台（Binary 1.90），以及上交所综合业务平台（EzSTEP 数据库接口：
  通过 SQL Server 委托表/成交表交换 STEP 消息），按网关分类自动切换。
- **前后端可合可分**：桌面端一体运行（Windows 单文件）；也可 Windows 只跑
  界面，连远程 Linux 后端做控制。
- **回报策略丰富**：固定模式（全部 / 部分成交、随机拆单、只确认、拒单等）
  + Lua 脚本自定义回报（沙箱执行）+ 手动逐笔回报；策略运行中热更新、即时生效。
- **测试辅助完备**：收发报文捕获与按字段解析、订单缓存与状态管理、
  多分区号、统计计数、操作日志，全部持久化可回看。
- **CLI 自动化**：`simx-cli` 命令行工具**主要为自动化测试而生**——改策略、
  手动回报、查询、启停网关，一条命令一件事、退出码可判断成败，可直接接入
  CI / 回归脚本。
- **自动升级**：目录发布 + 清单校验（size / sha256），客户端启动检查、
  下载、重启应用。

## 部署形态

| 形态 | 说明 |
| --- | --- |
| 一体模式（Windows） | 桌面客户端单文件运行，内嵌后端，直接接收柜台连接，界面控制一切 |
| 分离模式 | 界面跑在 Windows，后端跑在 Linux：后端独立运行、按策略自动发送回报，界面通过 WebSocket 远程控制；后端支持 `--auto-start` 开机自动恢复，可无人值守 |
| CLI | 连接任一形态的后端控制口，把界面上的常用操作做成命令，供自动化脚本调用 |

## 性能与规模

- **线程模型**：Rust + tokio 异步运行时，全程非阻塞 IO——每个平台一个监听
  任务，每条柜台连接收 / 发各一个任务；回报延迟由定时器驱动，不占线程空等。
- **规模**：网关 / 平台数量无硬性上限，几百个平台同时监听无压力；
  统计为原子计数，界面每秒轮询一次快照，开销固定。
- **连接约定**：每个平台同一时刻服务一个柜台连接（联调的一对一约定），
  断线重连即可。
- 回报延迟毫秒级可配（固定值或区间随机），用于模拟真实交易所的响应节奏。

## 程序清单与依赖

| 程序 | 作用 | 依赖 |
| --- | --- | --- |
| 桌面客户端 `simuxchange.exe`（Windows） | 界面 + 内嵌后端，本地模式直接接收柜台连接 | WebView2（Windows 10/11 自带） |
| `simx-server-musl` / `simx-server-glibc`（Linux）、`simx-server.exe`（Windows） | 独立后端：监听柜台 TCP、执行回报策略、提供 WebSocket 控制口 | musl 版静态无依赖（默认）；glibc 版用于 Oracle 查询，需 glibc ≥ 2.17 |
| `simx-update-server` | 升级服务器：扫描发布目录生成清单、提供文件下载 | 无（静态单文件） |
| `simx-cli`（Linux / Windows） | 自动化测试命令行工具（见上文 CLI 一条） | 无（静态单文件） |
